## How to Run

1. Clone the repository:
   ```bash
   git clone <your-repo-link>
   cd <your-repo-name>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the solutions directly:
   ```bash
   npx tsx src/solutions.ts
   ```
4. Or compile to JavaScript and run:
   ```bash
   npx tsc
   node dist/solutions.js
   ```
